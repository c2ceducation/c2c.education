AZ-305: Designing Microsoft Azure Infrastructure Solutions

This exam prep course is designed for candidates who have subject matter expertise in designing cloud and hybrid solutions that run on Microsoft Azure, including compute, network, storage, monitoring, and security. Candidates for this exam should have advanced experience and knowledge of IT operations, including networking, virtualization, identity, security, business continuity, disaster recovery, data platforms, and governance.

This course prepares you for the AZ-305 certification exam and covers all the skills measured, including designing identity, governance, and monitoring solutions; designing data storage solutions; designing business continuity solutions; and designing infrastructure solutions.

What you'll learn?

  • Design identity, governance, and monitoring solutions
  • Design data storage solutions for relational and non-relational data
  • Design business continuity solutions including backup, recovery, and high availability
  • Design infrastructure solutions including compute, application architecture, migrations, and networks
  • Implement Azure Active Directory and hybrid identity solutions
  • Design solutions using Azure Monitor, Log Analytics, and Azure Sentinel
  • Design data integration solutions using Azure Data Factory and Azure Synapse Analytics

Requirements

  • AZ-104: Microsoft Azure Administrator certification or equivalent knowledge
  • Experience with Azure networking, storage, compute, and identity services
  • Familiarity with Azure governance tools such as Azure Policy and RBAC
  • Understanding of business continuity and disaster recovery concepts
  • Basic knowledge of DevOps practices and CI/CD pipelines

Who Should Attend?

  • Azure Solutions Architects preparing for the AZ-305 exam
  • IT professionals with experience designing Azure solutions
  • Cloud architects looking to validate their Azure design skills
  • Professionals holding AZ-104 seeking to advance to architect-level certification

Course Curriculum

Module 1: Design Identity, Governance, and Monitoring Solutions

  • Design for Azure Active Directory
  • Design for hybrid identity
  • Design for Azure AD B2B and B2C
  • Design an authorization solution
  • Design governance with Azure Policy and Blueprints
  • Design for management groups and subscriptions
  • Design a monitoring solution with Azure Monitor and Log Analytics
  • Design for Azure Workbooks and Insights

Module 2: Design Data Storage Solutions

  • Design a data storage solution for relational data
  • Design data integration with Azure Data Factory
  • Recommend a data storage solution for semi-structured data
  • Design a data storage solution for non-relational data
  • Design Azure Blob Storage and Azure Files solutions
  • Design data tiering for Azure Blob Storage

Module 3: Design Business Continuity Solutions

  • Design for high availability using availability zones and sets
  • Design a solution for backup and disaster recovery
  • Design for Azure Site Recovery
  • Design for Azure Backup
  • Recommend a recovery solution for Azure hybrid and on-premises workloads

Module 4: Design Infrastructure Solutions

  • Design a compute solution (VMs, containers, serverless)
  • Design an application architecture
  • Design migrations using Azure Migrate
  • Design network solutions including VNets, peering, and VPN
  • Design for Azure ExpressRoute and Virtual WAN
  • Design for network security with NSGs, Azure Firewall, and DDoS Protection
